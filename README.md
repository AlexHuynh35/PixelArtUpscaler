# Pixel Art Upscaler

## Project Summary

This app takes a pixel art sprite and upscales it to a higher resolution.

---

## Tech Stack

| Language            | Libraries                                          |
|---------------------|----------------------------------------------------|
| Python              | Pillow (Image Upscaler), Tkinter (UI)              |

---

## How to Use

- To run the app:
    - Clone this repository
    - Install requirements (Pillow)
    - Launch the app

- To use the app:
    - Browse and select an image to upscale
    - Enter a scale factor
    - Verify output resolution
    - Click upscale
